==================================================

1. PURPOSE

==================================================

Luxe Horizon currently receives large numbers of product images through WhatsApp broadcasts, WhatsApp Status screenshots, friends and other miscellaneous sources.

The owner currently:

1. Saves product images/screenshots to the phone gallery.

2. Accumulates them throughout the week.

3. Separates products into Men's and Women's collections.

4. Creates large PDF catalogues, sometimes containing 100+ images/pages.

5. Sends the PDF manually and individually to customers through WhatsApp.

The purpose of this application is to dramatically simplify that process.

The new workflow must be:

SAVE IMAGES TO PHONE

→ MOBILE UPLOAD

→ AI-ASSISTED SORTING

→ QUICK ADMIN REVIEW

→ PUBLISH

→ LIVE CUSTOMER CATALOGUE

→ FILTERED LINKS / ADMIN PDF

→ WHATSAPP PRODUCT ENQUIRY

The owner will continue manually sending catalogue links/PDFs to customers through WhatsApp.

DO NOT automate customer broadcasting.

15. WHATSAPP ENQUIRY

==================================================

The customer's goal is to show Luxe Horizon exactly which visual product they are interested in.

IMPORTANT TECHNICAL CONSTRAINT:

A normal web page cannot silently attach a local image file directly into a WhatsApp conversation.

Therefore implement the enquiry using a unique public product URL.

When customer taps:

ENQUIRE ON WHATSAPP

open Luxe Horizon's WhatsApp conversation with a prefilled message similar to:

"Hi Luxe Horizon, I'm interested in this item 👇

[UNIQUE PRODUCT URL]

Is it available?"

Each public product URL must have correct social/Open Graph metadata so that WhatsApp can generate a rich preview using the exact PRIMARY product image where supported.

The product link must open the exact product.

The Luxe Horizon WhatsApp number must be configurable in Settings/environment configuration rather than hard-coded throughout components.
